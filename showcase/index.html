A clear campus attendance workflow

Project showcase · attendance runs with a local operator

Classroom maps, weekly courses, temporary check-in photos and responsible teacher review. An optional ESP32 companion supplies signed classroom proof.

Run the portal

  1. Download the project release and install Node 24.
  2. In its folder, run npm run demo.
  3. Open the printed address and use the generated private account file. A teacher starts the demonstration session.

Phones need the operator’s private trusted HTTPS setup. Optional Firebase mode provides account authentication and metadata persistence while the local server remains running.

This public page collects no attendance and does not contact any private backend. Automated facial recognition is not implemented: identity approval is performed by a teacher.
